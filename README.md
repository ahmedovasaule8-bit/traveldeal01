# TravelDeals

Адаптивный одностраничный сайт горящих туров. Работает полностью офлайн: данные находятся в `data/tours.js`, поэтому локальный сервер не требуется.

## Запуск

Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите содержимое этой папки в репозиторий, затем в настройках репозитория включите **Pages** для ветки `main` и папки `/ (root)`.

## Структура

- `index.html` — главная страница, фильтрация и подбор туров
- `tour.html` — страница выбранного предложения
- `css/style.css` — стили и адаптивная вёрстка
- `js/app.js` — интерфейс и логика сайта
- `data/tours.js` — редактируемый список туров

Цены и контакты демонстрационные. Перед публикацией замените их на актуальные.
